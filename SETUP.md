## Design system

- Custom IMPRESEO geometric wordmark embedded in the hero animation.
- No font files are bundled or redistributed.
- Coordinated motion language across hero, project architecture and capability network.
- Minimal use of third-party visual generators.
- Native GitHub interactions are used for expandable sections and navigation.
- Contribution trace is generated by GitHub Actions.

## GitHub limitation

A README cannot execute arbitrary JavaScript, WebGL, Three.js, CSS hover systems,
custom cursor physics or true pointer-reactive 3D. Those belong in a separate
GitHub Pages/portfolio experience.

This package is intentionally designed around what GitHub README pages actually support,
rather than pretending unsupported effects are interactive.
